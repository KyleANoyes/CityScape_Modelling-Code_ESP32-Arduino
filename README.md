# CityScape_Modelling-Code_ESP32-Arduino
Development of a 2x2 quadrant featuring extracted road network nodes from OpenStreetMaps with ESP32 LED illumination and dynamic LED control

This project contains all design files and application data used to create the models, run the ESP32, and schematic layouts. 

No AI has been used for this project, all source files are freely available for use as desired. This is a birthday gift and just a silly fun project to share :)
